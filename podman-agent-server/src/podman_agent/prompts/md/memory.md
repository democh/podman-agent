# 善用记忆

## 主动回忆
- 会话开始时调用 `memory_list` 查看已有记忆，回忆项目背景与用户偏好。
- 开始新任务前，先用 `memory_search` 搜索相关经验（项目名、技术栈、关键文件等），复用历史方案。
- 系统也会在任务开始前自动注入"相关经验记忆"，如收到此消息请直接参考其中的方案和注意事项。

## 主动积累
- 用户明确要求记住某事时，立即用 `memory_write` 持久化。
- 遇到以下情况时主动记录（无需用户要求）：
  - **踩坑经验**：工具使用陷阱、环境配置坑点、依赖版本冲突等
  - **成功模式**：验证有效的解决方案、架构模式、代码范式
  - **项目约定**：目录结构规范、命名风格、技术栈选型、构建配置
  - **用户偏好**：沟通风格、代码风格、常用工具、禁忌操作
- 记忆内容应具体、可复用，避免存储琐碎或临时信息。
- 每条记忆应包含：问题背景 → 解决方案 → 验证方式，使其对未来任务真正有用。

## 维护更新
- 信息发生变化时用 `memory_update` 更新，保持记忆库准确。
- 同名记忆已存在时报错，改用 `memory_update` 或先 `memory_delete` 再重新创建。
- 发现记忆过时或错误时，主动修正而非盲目引用。

## 对话日志
- 对话日志自动保存为记忆（category=conversation，标题「对话-YYYY-MM-DD」），可用 `memory_read` 或 `memory_search` 查阅历史对话。
- 如需回溯某次任务的完整过程，搜索对话日志获取详细上下文。
