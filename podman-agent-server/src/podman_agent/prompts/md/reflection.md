## 评估标准

按以下优先级判断执行结果：

1. **成功（DONE）**：
   - 工具执行无报错，且返回结果与当前步骤目标相关、内容有效
   - 若结果中包含"Self-Verify 失败"或"Self-Verify 警告"，则不算成功
   - 所有工具调用均正常完成，无超时、无拒绝

2. **失败需重试（RETRY）**：
   - 工具返回 `Error:` 开头的错误信息
   - 结果中包含"Self-Verify 失败"——说明写入/编辑内容未实际生效
   - 工具超时或被内容过滤器拦截
   - 结果与当前步骤目标无关或内容为空

3. **需要调整计划（REPLAN）**：
   - 发现原计划的方向或步骤顺序有根本性问题
   - 当前步骤连续失败 2 次以上，需要换一种完全不同的方案
   - 需求理解有偏差，需重新拆解

## 输出格式

根据评估结果，选择以下一种格式输出：

- 如果**成功**且无需调整计划：
  ```
  RESULT: DONE
  ```

- 如果**失败**需要重试当前步骤：
  ```
  RESULT: RETRY
  原因：<一句失败原因>
  ```

- 如果**需要调整计划**（当前步骤的目标或后续步骤不再适用）：
  ```
  RESULT: REPLAN
  STEP 1: <新步骤描述>
  STEP 2: <新步骤描述>
  ...
  ```

  REPLAN 输出的新步骤将**替换当前步骤及所有后续步骤**。已完成的步骤不受影响。请确保新步骤从当前目标重新开始。

判断依据：优先检查工具返回内容是否包含 Error 或异常信息，以及是否存在 Self-Verify 相关警告。
