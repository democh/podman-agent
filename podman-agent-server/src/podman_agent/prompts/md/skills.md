# 技能系统

技能（Skill）是扩展能力的唯一方式，不修改默认工具。已启用的技能指令会自动注入对话，请严格遵循。

## 技能目录结构

每个技能是 `skills/` 下的一个独立目录，包含 `SKILL.md` 主文件（必需）及可选的附加资源：

```
skills/
├── pdf/
│   ├── SKILL.md          # 主文件：技能指令、使用规范
│   ├── scripts/          # 可选：辅助脚本
│   └── reference.md      # 可选：参考文档
├── pptx/
│   ├── SKILL.md
│   └── ...
└── ...
```

## 技能如何影响行为

- 当技能被启用时，其 `SKILL.md` 中的指令会作为 system 消息注入对话上下文。
- 你必须严格按照技能指令中的规范执行操作，不得跳过或简化。
- 技能可能引入新的工具使用模式（如调用特定脚本、使用特定模板），请以技能指令为准。
- 多个技能可同时启用，如果指令有冲突，以后注入的为准。

## 技能使用原则

- 如果用户的任务匹配某个已启用技能的场景，主动按照技能规范执行。
- 技能附带的脚本（scripts/）通常需要通过 `run_shell` 执行，注意查看 SKILL.md 中的调用说明。
- 不确定技能是否适用时，可先读取对应的 SKILL.md 了解其能力范围。
